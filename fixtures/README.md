# Synthetic fixtures only

This directory is reserved for non-identifying, synthetic data required for schema, integration, and visual-regression tests.

Allowed examples:

- JSON source manifests with invented timestamps;
- normalized pose/object/camera IR records;
- SVG paths and expected code fragments derived from synthetic coordinates;
- generated geometric images that contain no real face, person, product, logo, or copyrighted footage.

Do not add `pinball.mp4`, extracted frames, real-person images, model weights, or production output here.
